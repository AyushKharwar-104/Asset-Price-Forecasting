# Asset Price Forecasting

A machine learning project for predicting asset prices using multiple correlated market signals.

## Overview
Analyzed time-series data and built forecasting models including ARIMA, Theil-Sen Regression, and XGBoost to predict asset price movements.

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Statsmodels, Matplotlib

## Project Structure
Data analysis, preprocessing, modeling, and evaluation
